# EDT ForceSync

Плагин для EDT, добавляющий в контекстное меню приложений команду **«Синхронизировано»** для принудительного перевода статуса приложения в «синхронизировано» (зелёная галочка) в обход полной синхронизации.

## Установка

- **Через P2 (GitHub Pages):** Help → Install New Software → Add → `https://timkonzt.github.io/EDT-ForceSync/`
- **Из ZIP-архива:** Help → Install New Software → Add → Archive → указать `edt_forcesync_<версия>.zip` из [релизов](https://github.com/TimkoNZT/EDT-ForceSync/releases)

## Предупреждение

После принудительной синхронизации все расширения, связанные с проектом, также получают статус «синхронизировано».
